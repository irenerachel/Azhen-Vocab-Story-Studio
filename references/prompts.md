# LibTV 出图提示词模板

所有图片默认先调用系统自带的生图工具。仅当系统没有可用工具，或自带工具不支持该素材必需的原生透明输出时，询问用户“是否使用 LibTV 插件生成这些图片？”。收到明确同意后才可为这些图片建画布、上传参考图或发起 LibTV 生图。 下列 LibTV 参数和命令仅适用于用户同意后的插件流程。

模型：`nebula-2.1`（General image V2.1）。每次 `params.count: 1`。角色姿势图都用 `left: [角色设定图节点]` 作为参考。

## 默认画风（用户没另给画风时用）

> 复古喜剧卡通的松弛平涂画风，轻快长弧线加少量突然转折，躯干细长，肩胯与手足比例有意错开，关节柔软轮廓清楚；表情靠眼睑高低、眉毛倾斜、嘴角小变化，显得机灵从容；双眼是白色眼面加小黑椭圆瞳孔，没有虹膜和高光；鼻子偏大的圆弧形；嘴角长弧线连到脸颊；眉眼轻微不对称；细深色外轮廓粗细自然变化，内部线条很少；纯平涂色块，无渐变无光影；轻盈俏皮，剪影清楚。

不要在提示词里写画家或工作室的名字，只描述画风特征；用“复古喜剧卡通”这类说法，不写“上世纪某某动画”。

## 1. 角色设定表（第一张，确认后才出其余图）

比例 16:9。

```
原创卡通角色设定图，N 个角色全身站姿从左到右一字排开，纯白背景，角色之间留空隙，没有文字。
画风：<画风>
角色从左到右：
1 <身份描述，不写故事里的专名>：<体型>，<发型发色>，<表情气质>；<服装与配色>。
2 同一个人物的另一套装扮：……
……
```

- 用“年轻女仆”“长腿贵族男子”这类描述代替“灰姑娘”“王子”等专名，专名容易触发版权过滤。
- 每个角色写清楚体型差异（细长 / 矮胖 / 竹竿），后面统一身高比例要靠它。
- 角色和道具的颜色沿用已确认的设定图。

## 2. 背景空镜

比例与成片画幅一致：横版 16:9，竖版 9:16。不接参考图。竖版背景把“留给角色表演的空地”写在画面中下部，上方三分之一留给天空或天花板。

```
经典喜剧动画的手绘背景画，完整不透明的纯场景，空镜无人物无动物无文字，无边框、水印、界面及待叠加的独立道具。<地点描述，写清楚前景、中景、远景>，画面中央下半部留出大片空地给角色表演。
画风：复古喜剧卡通背景，松弛平涂色块，形体用轻快长弧线和少量突然转折，透视有意夸张歪斜；细深色轮廓线粗细变化，内部线条克制；配色是<2～3 个低饱和颜色>，平涂无渐变，干笔小纹理，整体轻盈松动。
```

- 出图后先看前景有没有栅栏、灌木、栏杆这类会挡住角色的东西：有的话，角色要站到它们后面的空地上（见制作要点里的“前景遮挡”）。
- 需要代码画上去的东西（钟面、标牌）在提示词里写“空白的圆形区域”，别让模型画数字和文字。

## 3. 原生透明底角色与道具

开启生成工具的透明背景参数，输出带真实 Alpha 通道的 PNG。独立动物、姿势、道具及活动前景采用同一规则。

比例：单人 3:4，多人 16:9 或 4:3，道具 1:1。

```
参考{{Node <设定图节点ID>}}里第 K 个角色（<一句外观复述>），保持完全相同的长相、发型、服装和画风。单独画他/她一个人全身，<朝向>，<动作>，<表情：眼睑、眉毛、嘴角>。原生透明背景，主体外像素透明，没有地面、没有阴影、没有其他物体、没有文字。人物完整不出画。
```

道具和动物只说“按照{{Node …}}的画风”，不要求“相同角色”。

手持道具要把结构写死，否则容易画错（扫帚柄画成两根交叉的棍子）：写明“双手一上一下握住同一根扫帚柄，扫帚柄是一根连续的笔直木棍，中间没有断开、没有第二根棍子”。魔杖、雨伞、钓竿、绳子同理。出图后在联系表里放大检查。

## 被内容过滤拦下时怎么改

这次实际被拦的提示词和改法：

| 被拦的写法 | 原因判断 | 改成 |
|---|---|---|
| 礼服姑娘 + 玻璃鞋 + 转圈 | 太像知名动画的经典画面（第三方内容） | 去掉玻璃鞋，只写“杏色长裙张开双臂” |
| 王子单膝跪地捧着玻璃鞋 | 同上 | 改用已有的“王子看呆”站姿，鞋用代码叠加 |
| 提着裙摆飞奔下台阶、一只脚光着 | 经典画面 + 强调脚部 | 用同一张礼服图，奔跑靠代码的前倾和颠步实现 |
| 坐着伸出一条腿、脚穿鞋严丝合缝 | 强调脚部 | 改成“站着提起裙角，脚上穿着玻璃鞋” |
| 设定表里直接写“灰姑娘”“王子” | 专名 | 改成身份描述 |

规律：避开“专名 + 名场面”和对脚、腿的特写描述。同一句提示词重试没用，要换说法；连续两次失败就改用已有素材加代码动作。失败的任务不扣积分（两小时内返还）。
